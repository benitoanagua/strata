# Changelog

STRATA is a monorepo. Each publishable package keeps its own changelog:

- [`@strata/tokens`](packages/tokens/CHANGELOG.md)
- [`@strata/core`](packages/core/CHANGELOG.md)
- [`@strata/components`](packages/components/CHANGELOG.md)
- [`@strata/prose`](packages/prose/CHANGELOG.md)

Release policy: see [docs/RELEASING.md](docs/RELEASING.md). Versions are managed by Changesets; the four public packages are bumped together as a `fixed` group.
